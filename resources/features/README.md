# Features

Feature-by-feature breakdown of the app, split so the more complex
features get their own doc and the simpler ones share one:

- [Chat](chat.md) — the main AI companion conversation
- [WhatsApp](whatsapp.md) — inbox, campaigns, templates, inbound webhook
- [Payments & Subscriptions](payments.md) — Razorpay checkout, webhooks, access sync
- [Knowledge Base (RAG)](knowledge_base.md) — admin content that grounds chat replies
- [Other Features](other-features.md) — auth, journal, EFT, guided visualization, vision board, voice, notifications, masterclass/resources, segmentation

See also [../ARCHITECTURE.md](../ARCHITECTURE.md) for how these fit
together system-wide, and [../DATABASE.md](../DATABASE.md) for the data
